## 📱 اپلیکیشن موبایل

- پشتیبانی از Android و iOS
- رابط کاربری مدرن و کاربرپسند
- طراحی Dark Mode حرفه‌ای
- طراحی واکنش‌گرا برای تمامی اندازه‌های صفحه
- ارتباط بلادرنگ با دستگاه
- اتصال مجدد خودکار (Auto-Reconnect)
- Pairing امن و سریع
- ذخیره‌سازی تنظیمات و اطلاعات کاربر
- تغییر زبان بدون نیاز به راه‌اندازی مجدد برنامه
- کنترل کامل دستگاه از طریق تلفن همراه

## 🎵 امکانات صوتی

- پخش موسیقی از تلفن همراه
- مدیریت پلی‌لیست
- حالت‌های Shuffle و Repeat
- استخراج خودکار اطلاعات آهنگ
- نمایش نام آهنگ و هنرمند
- نمایش کاور آلبوم
- تحلیل لحظه‌ای صدا با FFT
- ویژوالایزر دایره‌ای صوتی
- پخش بی‌سیم صدا از طریق Bluetooth
- پشتیبانی از بلندگوهای استریو ۶ وات
- همگام‌سازی افکت‌های تصویری با موسیقی
- نمایش واکنش لحظه‌ای نمایشگر نسبت به صدا

---

## 🎚️ آنالایزر صوتی حرفه‌ای

- آنالایزر FFT با ۴۸ باند فرکانسی
- نمایش حرفه‌ای به سبک Kenwood
- افکت Peak Hold
- گرادیان‌های رنگی پویا
- واکنش بلادرنگ به موسیقی
- امکان شخصی‌سازی کامل رنگ‌ها
- چندین حالت نمایش مختلف

## 🎮 افکت‌های تصویری

- بیش از ۲۰ افکت انیمیشنی پویا
- افکت‌های الهام‌گرفته از کنسول‌های بازی
- افکت Victory
- افکت Combo
- افکت Explosion
- افکت Controller
- افکت X Button
- افکت‌های واکنش‌گرا به موسیقی
- انیمیشن‌های نرم و روان
- جابه‌جایی سریع بین افکت‌ها
